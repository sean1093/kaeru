# PR assets

Screenshots and other review assets for pull requests, kept off `main`.

- Path: `pr-<number>/<screen-id>-<locale>-<viewport>.png`, e.g. `pr-40/S21-zh-TW-390.png`.
- Embed in a PR with `https://raw.githubusercontent.com/sean1093/kaeru/pr-assets/pr-<number>/<file>.png`.
- Push with `git pull --rebase` first; paths never collide, so rebases are trivial.
